# ciw-external-schedule

External schedule of Ciw simulations.

This package is the code from the blog post
[External Schedule of Ciw Simulations](https://galenseilis.github.io/blog/posts/ciw-external-schedule/).

## Install

```bash
pip install "git+https://github.com/galenseilis/blog.git#subdirectory=blog/posts/ciw-external-schedule"
```

## Quick start

```python
from ciw_external_schedule import scheduled_changes
```
