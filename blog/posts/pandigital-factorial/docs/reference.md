# API reference

## `pandigital_factorial.pandigital`

### `is_pandigital(num)`

Check if number contains all digits 0-9.

### `search_pandigital_factorials_up_to(k=1001, m=200)`

Search factorials n from 0 to k-1, check last m digits.

### `format_results(results)`

Format results as markdown table.

### `main()`

Run search and print results.
