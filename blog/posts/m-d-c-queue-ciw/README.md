# M/D/c Queue Simulation (Ciw)

Implementation of a M/D/c queue simulation using Ciw.

## Installation

```bash
pip install git+https://github.com/seilis/blog.git#subdirectory=blog/posts/m-d-c-queue-ciw
```

## Quick Start

```bash
m-d-c-queue-ciw
```

## API

See `src/m_d_c_queue_ciw/simulate.py` for the `run_simulation()` function.
