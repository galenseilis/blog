# music-word-adjacency-graph-the-little-irish-girl documentation

This package holds the lyrics of *The Little Irish Girl* as a list of words and
builds a directed **word adjacency graph** from them: each word is a node and an
edge points from each word to the word that follows it in the lyrics.

The package follows the [Diátaxis](https://diataxis.fr/) structure:
