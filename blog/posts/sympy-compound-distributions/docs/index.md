# sympy-compound-distributions documentation

`sympy-compound-distributions` builds a SymPy
[compound distribution](https://en.wikipedia.org/wiki/Compound_probability_distribution)
in which a normal variable's mean and scale are themselves random variables. It
is the packaged version of the example in the blog post.

The package follows the [Diátaxis](https://diataxis.fr/) structure:

| I want to... | Read |
| --- | --- |
| learn the package by doing | [Tutorial](tutorials.md) |
| solve a specific problem | [How-to guides](how-to-guides.md) |
| look up functions and classes | [Reference](reference.md) |
| understand the ideas and trade-offs | [Explanation](explanation.md) |

## Contents

- [Tutorial](tutorials.md): build the example distribution step by step.
- [How-to guides](how-to-guides.md): change the parameters and evaluate the
  density.
- [Reference](reference.md): the public API and the console script.
- [Explanation](explanation.md): what a compound distribution is, and why the
  random parameters matter.
