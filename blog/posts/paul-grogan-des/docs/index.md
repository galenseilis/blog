# paul-grogan-des documentation

This package is a hand-written discrete-event simulation of a single-server
queue, plus a Ciw implementation of the same system.

The package follows the [Diátaxis](https://diataxis.fr/) structure:

| I want to... | Read |
| --- | --- |
| learn the package by doing | [Tutorial](tutorials.md) |
| solve a specific problem | [How-to guides](how-to-guides.md) |
| look up functions and classes | [Reference](reference.md) |
| understand the ideas and trade-offs | [Explanation](explanation.md) |

## Contents

- [Tutorial](tutorials.md): run the simulation and interpret its counters.
- [How-to guides](how-to-guides.md): change rates, horizon, and seeding.
- [Reference](reference.md): the public API and the console script.
- [Explanation](explanation.md): event-advance simulation versus Ciw.
