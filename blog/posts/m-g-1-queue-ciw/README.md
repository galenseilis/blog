# M/G/1 Queue Simulation (Ciw)

Implementation of a M/G/1 queue simulation using Ciw.

## Installation

```bash
pip install git+https://github.com/seilis/blog.git#subdirectory=blog/posts/m-g-1-queue-ciw
```

## Quick Start

```bash
m-g-1-queue-ciw
```

## API

See `src/m_g_1_queue_ciw/simulate.py` for the `run_simulation()` function.
