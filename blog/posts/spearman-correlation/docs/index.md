# spearman-correlation documentation

`spearman-correlation` contains two visual aids for thinking about Spearman's
rank correlation: a Markdown table of the possible rank permutations of four
observations, and a grid figure that draws each permutation as a checkerboard.

The package follows the [Diátaxis](https://diataxis.fr/) structure:

| I want to... | Read |
| --- | --- |
| learn the package by doing | [Tutorial](tutorials.md) |
| solve a specific problem | [How-to guides](how-to-guides.md) |
| look up functions and classes | [Reference](reference.md) |
| understand the ideas and trade-offs | [Explanation](explanation.md) |

## Contents

- [Tutorial](tutorials.md): print the permutation table and draw the grid.
- [How-to guides](how-to-guides.md): change the sample size, the output path,
  and compute a rank correlation.
- [Reference](reference.md): the public API and the console scripts.
- [Explanation](explanation.md): why Spearman's coefficient is Pearson's on the
  ranks, and what comonotonicity means.
