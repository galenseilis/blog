# notes-process-modelling documentation

`notes-process-modelling` implements a **labelled transition system** and its
**synchronous product**. It is the code from a set of notes on the BPMAG
process-modelling lectures, where systems are described as states and labelled
transitions between them.

The package follows the [Diátaxis](https://diataxis.fr/) structure:

| I want to... | Read |
| --- | --- |
| learn the package by doing | [Tutorial](tutorials.md) |
| solve a specific problem | [How-to guides](how-to-guides.md) |
| look up functions and classes | [Reference](reference.md) |
| understand the ideas and trade-offs | [Explanation](explanation.md) |

## Contents

- [Tutorial](tutorials.md): build a labelled transition system and take a
  synchronous product.
- [How-to guides](how-to-guides.md): build a product of several systems and
  inspect the result.
- [Reference](reference.md): the `LTS` class and the console script.
- [Explanation](explanation.md): what a labelled transition system is, and what
  the synchronous product does and does not capture.
