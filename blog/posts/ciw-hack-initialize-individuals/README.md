# ciw-hack-initialize-individuals

Hack to initialize Ciw queues with individuals.

This package is the code from the blog post
[Can Ciw Queues be Initialized With Individuals?](https://galenseilis.github.io/blog/posts/ciw-hack-initialize-individuals/).

## Install

```bash
pip install "git+https://github.com/galenseilis/blog.git#subdirectory=blog/posts/ciw-hack-initialize-individuals"
```
