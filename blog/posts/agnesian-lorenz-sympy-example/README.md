# agnesian-lorenz-sympy-example

Express the Agnesian of order one of the Lorenz system using SymPy.

This package is extracted from the blog post
[Expressing the Agnesian Equation of Order One of the Lorenz System Using SymPy](https://galenseilis.github.io/blog/posts/agnesian-lorenz-sympy-example/).

## Install

```bash
pip install "git+https://github.com/galenseilis/blog.git#subdirectory=blog/posts/agnesian-lorenz-sympy-example"
```

Requires Python 3.11 or newer.

## Quick start

```python
from agnesian_lorenz_sympy_example.agnesian import agnesian_lorenz_order1

print(agnesian_lorenz_order1())
```

## CLI

```bash
agnesian-lorenz-sympy-example
```
