# se-graveyard-convex-verhulst-params documentation

This package derives the Hessian of the Verhulst (logistic) growth function with
respect to its parameters using SymPy.

The package follows the [Diátaxis](https://diataxis.fr/) structure:

| I want to... | Read |
| --- | --- |
| learn the package by doing | [Tutorial](tutorials.md) |
| solve a specific problem | [How-to guides](how-to-guides.md) |
| look up functions and classes | [Reference](reference.md) |
| understand the ideas and trade-offs | [Explanation](explanation.md) |

## Contents

- [Tutorial](tutorials.md): build the Hessian and inspect it.
- [How-to guides](how-to-guides.md): substitute values and test definiteness.
- [Reference](reference.md): the public API and the console script.
- [Explanation](explanation.md): convexity, the Hessian, and why to use SymPy.
