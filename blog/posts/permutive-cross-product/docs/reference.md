# Reference

## API

- `find_permutive_cross_products(dim: int = 3) -> list[sp.Matrix]`
- `find_4perm_cross_products(dim: int = 3, max_results: int | None = None) -> pd.DataFrame`

## CLI

- `permutive-cross-product` — prints LaTeX of found vectors
- `permutive-cross-product-4perm` — prints markdown table (limited results by default)
