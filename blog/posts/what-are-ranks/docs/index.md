# what-are-ranks documentation

`what-are-ranks` builds a small table comparing the tie-handling methods of
`scipy.stats.rankdata`. It is the packaged code from the blog post, kept tiny on
purpose: the point is the *interpretation* of ranks, not a large library.

The package follows the [Diátaxis](https://diataxis.fr/) structure:

| I want to... | Read |
| --- | --- |
| learn the package by doing | [Tutorial](tutorials.md) |
| solve a specific problem | [How-to guides](how-to-guides.md) |
| look up functions and classes | [Reference](reference.md) |
| understand the ideas and trade-offs | [Explanation](explanation.md) |

## Contents

- [Tutorial](tutorials.md): build the comparison table on the post's sample.
- [How-to guides](how-to-guides.md): choose a ranking method and rank your own
  data.
- [Reference](reference.md): the public API and the console script.
- [Explanation](explanation.md): what a rank is, why ties matter, and the
  difference between rankings and ratings.
