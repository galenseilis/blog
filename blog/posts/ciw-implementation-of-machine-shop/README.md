# ciw-implementation-of-machine-shop

Ciw implementation of SimPy's machine shop example.

This package is the code from the blog post
[A Ciw Implementation of SimPy's Machine Shop Example](https://galenseilis.github.io/blog/posts/ciw-implementation-of-machine-shop/).

## Install

```bash
pip install "git+https://github.com/galenseilis/blog.git#subdirectory=blog/posts/ciw-implementation-of-machine-shop"
```
