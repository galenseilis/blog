# API reference

## `m_g_k_queue_ciw.queue`

### `run_simulation(seed=2018, arrival_time=1.0, service_shape=0.6, service_scale=1.2, num_servers=2, horizon=365.0)`

Run a simulation of an M/G/k queue using Ciw.

Returns a list of all simulation records.

### `main()`

Execute the simulation and print results.
