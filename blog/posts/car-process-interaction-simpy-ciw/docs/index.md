# car-process-interaction-simpy-ciw documentation

This package contains two implementations of the same small discrete-event
simulation: a SimPy **process-interaction** model of an electric car and a Ciw
**queueing-network** model that reproduces the same event log.

The package follows the [Diátaxis](https://diataxis.fr/) structure:

| I want to... | Read |
| --- | --- |
| learn the package by doing | [Tutorial](tutorials.md) |
| solve a specific problem | [How-to guides](how-to-guides.md) |
| look up functions and classes | [Reference](reference.md) |
| understand the ideas and trade-offs | [Explanation](explanation.md) |

## Contents

- [Tutorial](tutorials.md): run the Ciw simulation and read the log.
- [How-to guides](how-to-guides.md): change timings and messages.
- [Reference](reference.md): the public API and the console script.
- [Explanation](explanation.md): process interaction versus queueing networks.
