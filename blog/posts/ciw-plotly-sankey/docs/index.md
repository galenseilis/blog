# ciw-plotly-sankey documentation

`ciw-plotly-sankey` runs [Ciw](https://ciw.readthedocs.io/en/latest/)'s cafe
example and draws the resulting customer flows as a
[Plotly](https://plotly.com/python/) Sankey diagram.

The package follows the [Diátaxis](https://diataxis.fr/) structure:

| I want to... | Read |
| --- | --- |
| learn the package by doing | [Tutorial](tutorials.md) |
| solve a specific problem | [How-to guides](how-to-guides.md) |
| look up functions and classes | [Reference](reference.md) |
| understand the ideas and trade-offs | [Explanation](explanation.md) |

## Contents

- [Tutorial](tutorials.md): run the example and render the diagram.
- [How-to guides](how-to-guides.md): reuse the pipeline on other Ciw models and
  change the node labels.
- [Reference](reference.md): the seven pipeline modules and the console script.
- [Explanation](explanation.md): why a Sankey diagram shows what happened rather
  than a plan, and the quirks of Ciw's records.
