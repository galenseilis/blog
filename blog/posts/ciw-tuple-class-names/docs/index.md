# ciw-tuple-class-names documentation

`ciw-tuple-class-names` shows how to use **tuples** as customer-class names in
[Ciw](https://ciw.readthedocs.io/en/latest/) queueing networks, and where that
convenience breaks down.

The package follows the [Diátaxis](https://diataxis.fr/) structure:

| I want to... | Read |
| --- | --- |
| learn the package by doing | [Tutorial](tutorials.md) |
| solve a specific problem | [How-to guides](how-to-guides.md) |
| look up functions and classes | [Reference](reference.md) |
| understand the ideas and trade-offs | [Explanation](explanation.md) |

## Contents

- [Tutorial](tutorials.md): build a network whose classes are tuples and run it.
- [How-to guides](how-to-guides.md): reproduce the `TypeError` and apply the
  padding fix.
- [Reference](reference.md): the three modules and the console script.
- [Explanation](explanation.md): why tuple ordering matters and why immutable,
  ordered attribute classes are the natural next step.
